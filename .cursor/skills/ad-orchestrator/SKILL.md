# Ad Campaign Orchestrator

대행사 캠페인은 **한 번에 한 팀만** 작업한다. 이전 단계 산출물을 디스크에 저장한 뒤, 다음 팀이 그 파일만 읽고 이어간다.

## 절대 규칙

1. **병렬 금지** — AE·카피·이미지·영상·옥외·CEO를 동시에 쓰지 않는다.
2. **건너뛰기 금지** — 이전 단계 `outputs/` 파일이 없으면 다음 단계로 가지 않는다.
3. **저장 후 진행** — 각 단계 종료 시 지정 경로에 파일을 쓴 뒤, 사용자에게 "○○ 단계 완료"를 알리고 다음 단계로 넘어간다 (한 턴에서 전체를 몰아쓰지 말 것 — 사용자가 "계속"이라고 하면 다음 단계 실행).
4. **입력 없으면 중단** — `brief/brand-brief.md` 또는 사용자 메시지에 브랜드·목표·타겟이 없으면 1단계 전에 브리프를 요청한다.

## 산출물 경로 (고정)

| 단계 | 스킬 | 출력 파일 |
|------|------|-----------|
| 0 | (사용자) | `brief/brand-brief.md` |
| 1 | ad-ae | `outputs/01_ae_캠페인_방향성_기획서.md` |
| 2 | ad-copywriter | `outputs/02_copy_핵심_카피.md` |
| 3 | ad-image | `outputs/03_image_광고_시안.md` |
| 4 | ad-video | `outputs/04_video_광고_시안.md` |
| 5 | ad-outdoor | `outputs/05_outdoor_광고_시안.md` |
| 6 | ad-ceo-review | `outputs/06_ceo_검수.md` (50점 미만일 때만) |

## 실행 순서

```
브리프 확인
  → ad-ae (기획서 저장) ── 대기/완료 확인
  → ad-copywriter (02 저장) ── 대기
  → ad-image (03 저장) ── 대기
  → ad-video (04 저장) ── 대기
  → ad-outdoor (05 저장) ── 대기
  → ad-ceo-review (채점; 50점 이상이면 06 파일 생략)
```

## 단계별 호출 문장 (내부 페르소나)

각 단계 시작 시 해당 스킬의 SKILL.md 규칙을 **전부** 적용한다.

- 1단계: "AE야, 이 브랜드 기획서 만들어줘" → `ad-ae`
- 2단계: "카피야, 이 기획서 보고 카피 써줘" → `ad-copywriter` (입력: `01_*`)
- 3단계: "이미지팀, 이제 네 차례야" → `ad-image` (입력: `01_*`, `02_*`)
- 4단계: "영상팀, 시안 잡아줘" → `ad-video` (입력: `01_*`, `02_*`, `03_*` 참고)
- 5단계: "옥외팀, 옥외 시안 부탁해" → `ad-outdoor` (입력: `01_*`, `02_*`)
- 6단계: "대표님 검수해주세요" → `ad-ceo-review` (입력: `outputs/` 전부)

## 재작업 루프

CEO 검수 **50점 미만** 시 `outputs/06_ceo_검수.md`의 팀별 지시만 따른다.

- AE 지적 → 1단계만 수정·덮어쓰기 후 **2단계부터 순서대로 재실행**
- 카피만 지적 → 2부터 재실행
- 이미지/영상/옥외만 지적 → 해당 단계만 수정 후 CEO 재검수

## 사용자에게 보고할 때

- 완료 단계명 + 저장 파일 경로
- 다음 단계 예고 ("계속하면 카피 단계로 넘어갑니다")
- CEO **통과(50점+)** 시: 총점·항목별 점수만 간단히. 별도 06 파일 없음.
