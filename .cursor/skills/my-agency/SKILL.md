# My Agency — 3단계 캠페인 파이프라인

**트리거:** `/myagency` · `내 캠페인 만들어줘` · `myagency`

워크스페이스에 `.cursor/agents/my-ae.md`, `my-copywriter.md`, `my-reviewer.md`가 있어야 한다.  
산출물은 프로젝트 루트 기준 `brief/`, `outputs/`에 저장한다.

## 실행 전 확인

- [ ] 브리프: `brief/brand-brief.md` **또는** 사용자 메시지에 학교명·목표·타겟이 있음
- [ ] 없으면 1단계 전에 브리프만 요청하고 파이프라인을 시작하지 않음

## 절대 규칙

1. **순서 고정** — 1 → 2 → 3. 건너뛰기·병렬 금지.
2. **파일 게이트** — 2단계는 `01_*` 저장 후에만, 3단계는 `01_*`·`02_*` 저장 후에만 진행.
3. **에이전트 규칙 준수** — 각 단계에서 해당 `.cursor/agents/*.md`의 역할·규칙·금지 사항을 **전부** 적용.
4. **한 턴 한 단계** — 사용자가 "한 번에 끝까지"라고 명시하지 않으면, 단계 완료 보고 후 다음 단계로 넘어간다.

---

## 진행 대본

### 0. 오프닝 (트리거 수신 시)

```
[My Agency] 새 학기 홍보 캠페인 파이프라인을 시작합니다.
브리프 확인 → 1.AE → 2.카피 → 3.검수 순으로 진행합니다.
```

브리프가 없으면 `brief/brand-brief.template.md` 안내 후 **중단**.

---

### 1단계: my-ae 실행

**호출 문장 (내부):**  
> AE야, 브리프 보고 새 학기 홍보 캠페인 방향성 기획서 만들어줘.

**적용 에이전트:** `.cursor/agents/my-ae.md`

**입력**

- `brief/brand-brief.md` (있으면 읽기)
- 없으면 사용자 메시지의 브리프

**작업**

- 기획서 7개 섹션 + AE 종합 코멘트 작성
- 가치 중심, 타겟 인사이트·톤앤매너 명확히

**저장 (필수)**

| 파일 |
|------|
| `outputs/01_ae_새학기_홍보_기획서.md` |

**1단계 완료 보고**

```
✅ 1단계 완료 (my-ae)
저장: outputs/01_ae_새학기_홍보_기획서.md
다음: my-copywriter — "계속" 또는 "2단계"라고 하면 진행합니다.
```

`01_*` 파일이 디스크에 없으면 2단계로 가지 않음.

---

### 2단계: my-copywriter 실행

**호출 문장 (내부):**  
> 카피야, 1단계 기획서 보고 핵심 카피 써줘.

**적용 에이전트:** `.cursor/agents/my-copywriter.md`

**입력 (전달)**

- **필수:** `outputs/01_ae_새학기_홍보_기획서.md` 전문을 읽고 반영
- 없으면: "1단계 기획서가 없습니다" 보고 후 **중단**

**작업**

- 메인 카피 1줄
- 대안 A(감성) · 대안 B(이성) 각 1줄
- 카피 선정 이유 3줄 이상

**저장 (필수)**

| 파일 |
|------|
| `outputs/02_copy_새학기_핵심_카피.md` |

**2단계 완료 보고**

```
✅ 2단계 완료 (my-copywriter)
저장: outputs/02_copy_새학기_핵심_카피.md
다음: my-reviewer — "계속" 또는 "3단계"라고 하면 검수합니다.
```

---

### 3단계: my-reviewer 실행

**호출 문장 (내부):**  
> 검수자님, 1·2단계 산출물 검수해주세요.

**적용 에이전트:** `.cursor/agents/my-reviewer.md` (`readonly: true`)

**입력 (전달)**

- `outputs/01_ae_새학기_홍보_기획서.md`
- `outputs/02_copy_새학기_핵심_카피.md`
- 하나라도 없으면 누락 파일명만 알리고 **중단**

**작업**

- 7항목 × 10점 = 70점 만점 채점
- 칭찬 선행 금지, 감점마다 이유 1문장
- **50점 이상** → 통과 / **50점 미만** → AE·카피 팀별 재작업 지시

**검수자는 파일을 쓰지 않음** — 채점·지시는 채팅으로만.  
**오케스트레이터(당신)**가 아래 형식으로 검수 결과를 **반드시 저장**:

| 파일 |
|------|
| `outputs/03_review_검수_결과.md` |

**`03_review` 저장 템플릿**

```markdown
# 검수 결과 — 새 학기 홍보 캠페인

## 판정
[통과 / 재작업]

## 총점
[ ] / 70 (기준: 50점 이상 통과)

## 항목별 점수
| 항목 | 점수 | 코멘트 |
|------|------|--------|
| 전략적 일관성 | /10 | |
| 타겟·인사이트 적합성 | /10 | |
| 카피 임팩트 | /10 | |
| 톤앤매너 준수 | /10 | |
| 메시지 명확성 | /10 | |
| 차별화·신선함 | /10 | |
| 전체 완성도 | /10 | |

## 재작업 지시 (50점 미만일 때만)
### AE
- ...

### 카피
- ...

## 검수 요약
[3~5문장, 냉철·구체]
```

**3단계 완료 보고**

**통과 시**

```
✅ 3단계 완료 (my-reviewer) — 통과
총점: XX/70
저장: outputs/03_review_검수_결과.md
산출물: 01 기획서 · 02 카피 · 03 검수 결과
```

**재작업 시**

```
⚠️ 3단계 완료 — 재작업 필요 (XX/70)
저장: outputs/03_review_검수_결과.md
→ AE만 수정 후 2→3 재실행 / 카피만 수정 후 3만 재실행 (03 덮어쓰기)
```

---

## 한 번에 끝까지 실행

사용자가 **"한 번에"**, **"끝까지"**, **"3단계 연속"**이라고 하면  
위 1→2→3을 **중간 대기 없이** 연속 실행. 각 단계마다 파일 저장은 생략하지 않음.

## 재작업 루프

`03_review`가 **재작업**이면:

| 지시 대상 | 다시 실행 |
|-----------|-----------|
| AE만 | 1 → 2 → 3 |
| 카피만 | 2 → 3 |
| 둘 다 | 1 → 2 → 3 |

수정 후 `03_review_검수_결과.md`는 최신 검수로 **덮어쓰기**.

## 산출물 요약

| 단계 | 에이전트 | 출력 |
|------|----------|------|
| 1 | my-ae | `outputs/01_ae_새학기_홍보_기획서.md` |
| 2 | my-copywriter | `outputs/02_copy_새학기_핵심_카피.md` |
| 3 | my-reviewer + 저장 | `outputs/03_review_검수_결과.md` |

---

## 단계별 단독 실행

트리거 없이 아래만 요청된 경우 **해당 단계만** 실행하되, 파일 게이트는 동일:

- `AE 기획서` → 1단계만
- `카피` → 2단계만 (`01_*` 필수)
- `검수` → 3단계만 (`01_*`, `02_*` 필수)
